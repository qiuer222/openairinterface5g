# Agent Instructions

## NR-Only Modification Rule

All code changes must be limited to NR (New Radio / 5G) relevant files only.
Do **not** modify LTE code paths or LTE-specific files.

### NR-Only Files

These directories/files are safe for NR-only modifications:

- `openair1/PHY/NR_*` — NR PHY layer (estimation, transport, modulation, etc.)
- `openair1/SCHED_NR/` — NR scheduler
- `openair2/LAYER2/NR_MAC_*` — NR MAC layer
- `openair2/LAYER2/NR_RLC/` — NR RLC
- `openair2/RRC/NR_*` — NR RRC
- `executables/nr-*` — NR executables and headers

### Shared Files (Use With Care)

The following files are shared between LTE and NR. Modifications must be
limited to adding fields or flags that are only consumed by NR code paths:

- `executables/softmodem-common.h` / `executables/softmodem-common.c`
  — Common softmodem parameters and CLI option definitions. Adding a
    boolean flag here is acceptable as long as only NR code reads it.
- `common/` — Only modify if the change is genuinely generic (utility
    functions, data types used by both LTE and NR).

### Files to Avoid

Do **not** modify any file under:

- `openair1/PHY/LTE_*` — LTE PHY
- `openair2/LAYER2/MAC/` — LTE MAC (eNB)
- `openair2/LAYER2/MAC_UE/` — LTE MAC (UE)
- `openair2/RRC/LTE/` — LTE RRC
- `openair3/NAS/` — NAS layer (shared but needs careful review)
- `executables/lte-*` — LTE executables
