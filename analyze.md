

Goal
Implement a standalone Python analysis module that loads the CSV file generated by the OAI GUI together with the recorded CSI channel matrices, computes multiple theoretical link-capacity metrics, predicts throughput using different channel-quality criteria, and evaluates which criterion best matches the measured throughput and stream selection behavior.

Input

1. CSV generated by the GUI (one row per iperf update event).
2. CSI channel matrices recorded at the same sampling instants.

   * Each timestamp contains channel estimates H(k) for multiple valid subcarriers.
   * Invalid / missing subcarriers should be ignored.
   * The CSI timestamps are aligned with the CSV timestamps.

Critical Requirement: Verify OAI Channel Scaling

Before performing any capacity computation, inspect the OpenAirInterface source code to determine how the recorded CSI values are generated.

The recorded CSI is likely not the physical complex channel coefficient but an internally scaled representation (fixed-point / Q-format / FFT-scaled / AGC-scaled).

Trace the recording path from the GUI logging code back to the channel estimation implementation and identify:

* the original channel estimate variable,
* its numeric type,
* any FFT/IFFT normalization,
* fixed-point scaling factors,
* AGC / digital gain normalization,
* antenna gain normalization,
* averaging factors,
* and any additional power scaling applied before writing to shared memory or file.

Derive the conversion from the recorded CSI values to a physically meaningful channel matrix whose power is consistent with the measured received signal power.

Validate the scaling by checking that:

* average ||H||²,
* reconstructed receive power,
* and measured RSRP

are mutually consistent.

Document all discovered scaling factors and implement a reusable normalization function before any SVD/ZF capacity calculation.

Metrics

1. Measured Throughput
   Use the throughput column from the GUI CSV directly.

2. RSRP
   Use the RSRP column from the GUI CSV directly.

3. Average SVD Capacity (Equal Power Allocation)
   For each timestamp:

* For every valid subcarrier:

  * Obtain normalized channel matrix H.
  * Compute SVD:
    H = U Σ V^H
  * Let singular values be σ_i.
  * Assume total transmit power P and noise power N0.
  * Equal power across Ns streams:
    P_i = P / Ns
  * Capacity:
    C = Σ_i log2(1 + (P_i / N0) * σ_i²)
* Average the capacity over all valid subcarriers.

4. Best-Stream SVD Capacity
   For each timestamp:

* Traverse stream number r = 1 ... min(Nt, Nr).
* Use the strongest r singular values.
* Equal power among r streams.
* Compute:
  C_r = Σ_{i=1}^r log2(1 + (P/rN0) * σ_i²)
* Select the maximum C_r.
* Record:
  best_svd_capacity
  optimal_stream_number_svd

5. Best-Stream ZF Capacity
   For each timestamp:

* Traverse stream number r = 1 ... min(Nt, Nr).
* Build ZF precoder using the first r streams.
* Normalize total transmit power.
* Equal power allocation among streams.
* Compute post-processing SINR for each stream.
* Capacity:
  C_r = Σ_i log2(1 + SINR_i)
* Select the maximum C_r.
* Record:
  best_zf_capacity
  optimal_stream_number_zf

Normalization

* Use the normalized physical channel matrix derived from the OAI scaling analysis.
* Use the same SNR assumption for all capacity calculations.
* Make SNR configurable (default 10 dB).
* Ignore subcarriers without valid CSI.
* Average capacities only over valid subcarriers.

Correlation Analysis

Compute both Pearson and Spearman correlation coefficients between measured throughput and:

* RSRP
* Average SVD capacity
* Best-stream SVD capacity
* Best-stream ZF capacity

Also compute linear regression and report:

* R²
* RMSE
* MAE

Throughput Prediction Accuracy

Use each metric as a predictor of throughput.

For each criterion:

* RSRP
* Average SVD capacity
* Best-stream SVD capacity
* Best-stream ZF capacity

Fit a regression model:

* Linear regression (mandatory)
* Optional polynomial regression (degree=2)

Evaluate prediction accuracy using:

* Pearson correlation
* Spearman correlation
* RMSE
* MAE
* MAPE
* R²

Rank all predictors from most accurate to least accurate and generate a comparison table.

Stream Selection Accuracy

Evaluate how accurately different capacity metrics predict the optimal transmission stream number.

Assume the measured throughput corresponds to the best achievable stream configuration.

For each timestamp:

* Determine the stream number that maximizes measured throughput (or infer from available transmission metadata if present).
* Compare it with:
  optimal_stream_number_svd
  optimal_stream_number_zf

Report:

* Stream selection accuracy (%)
* Confusion matrix
* Mean absolute stream-number error
* Distribution of prediction errors
* Accuracy conditioned on RSRP ranges and channel condition number ranges

The final report should answer:

1. Which metric has the highest Pearson correlation with measured throughput?
2. Which metric provides the most accurate throughput prediction (lowest RMSE / highest R²)?
3. Does adaptive stream selection outperform fixed-stream capacity estimation?
4. Between SVD-based and ZF-based stream selection, which predicts the optimal stream number more accurately?
5. What scaling factors exist in the OAI CSI recording path, and how does channel-power normalization affect the correlation results?
6. Under which channel conditions (high/low RSRP, high/low condition number) does each method perform best?
